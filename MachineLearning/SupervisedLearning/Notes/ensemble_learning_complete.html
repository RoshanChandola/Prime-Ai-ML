Foundation

Why combining models helps

Any single model's total prediction error decomposes into three independent terms. For a learned function $\hat{f}(x)$ trying to predict a true value $y$:

$$\underbrace{E\!\left[(y - \hat{f}(x))^2\right]}_{\text{Total expected error}} = \underbrace{\text{Bias}(\hat{f}(x))^2}_{\text{systematic error}} + \underbrace{\text{Var}(\hat{f}(x))}_{\text{sensitivity to training data}} + \underbrace{\sigma^2}_{\text{irreducible noise}}$$
Notation
$y$
true target value for input $x$
$\hat{f}(x)$
model's predicted value for input $x$
$E[\cdot]$
expectation, i.e., the average over all possible training sets of size $n$
$\text{Bias}(\hat{f}(x))$
$E[\hat{f}(x)] - f(x)$: how far the average prediction drifts from the truth
$\text{Var}(\hat{f}(x))$
$E\!\left[(\hat{f}(x) - E[\hat{f}(x)])^2\right]$: how widely the prediction swings across training sets
$\sigma^2$
variance of $y$ around $f(x)$ — the noise floor no algorithm can beat

The variance reduction formula

If we average $B$ independent identically-distributed estimators, each with variance $\sigma^2$ and pairwise correlation $\rho$ between their errors, the averaged estimator has variance:

$$\text{Var}\!\left(\frac{1}{B}\sum_{b=1}^{B}Z_b\right) = \rho\,\sigma^2 + \frac{1 - \rho}{B}\,\sigma^2$$
Notation
$B$
number of models being averaged
$Z_b$
prediction from the $b$-th model
$\rho$
average Pearson correlation between errors of any pair of models
$\sigma^2$
variance of a single model's error

As $B \to \infty$, the second term vanishes, leaving $\rho\,\sigma^2$. This is why ensemble design is ultimately about keeping $\rho$ small: every method below is a distinct strategy for creating diverse, decorrelated models without sacrificing individual accuracy.

Method · Parallel · Variance reduction

Bagging — Bootstrap Aggregating

Breiman (1996) proposed training many identical model architectures on different bootstrap resamples of the data, then averaging their predictions. Because no model ever sees the exact same data, their errors are partially decorrelated, lowering $\rho$.

each bootstrap sample D_b* resamples n rows with replacement; ~63.2% unique rows per sample

Algorithm

  1. For each iteration $b = 1, \dots, B$:
    • Draw a bootstrap sample $D_b^*$ of size $n$ from the training set $D = \{(x_i, y_i)\}_{i=1}^{n}$ by sampling with replacement.
    • Train base learner $\hat{f}^{(b)}$ using only $D_b^*$.
  2. Aggregate predictions:
    • Regression: $\hat{f}_{\text{bag}}(x) = \dfrac{1}{B}\displaystyle\sum_{b=1}^{B}\hat{f}^{(b)}(x)$
    • Classification: $\hat{f}_{\text{bag}}(x) = \arg\max_{k}\displaystyle\sum_{b=1}^{B}\mathbb{1}(\hat{f}^{(b)}(x) = k)$
Notation
$D$
original training dataset of $n$ labeled pairs $(x_i, y_i)$
$D_b^*$
$b$-th bootstrap resample: $n$ rows drawn with replacement from $D$ (each row has probability $1/n$ of being chosen each draw)
$n$
number of training samples
$B$
total number of base models trained; typically 100–500 trees for tree-based bagging
$\hat{f}^{(b)}$
the model trained exclusively on $D_b^*$
$\hat{f}_{\text{bag}}$
the final bagged ensemble prediction
$k$
a candidate class label in a classification problem
$\mathbb{1}(\cdot)$
indicator function: equals 1 when its argument is true, 0 otherwise
$\arg\max_k$
"the value of $k$ that maximises the expression that follows"

Out-of-bag (OOB) estimation

Because each $D_b^*$ is drawn with replacement, each sample has a $(1 - 1/n)^n \xrightarrow{n\to\infty} e^{-1} \approx 0.368$ probability of never appearing in $D_b^*$. Those excluded rows form the out-of-bag set for model $b$. The OOB error estimate is:

$$\hat{\varepsilon}_{\text{OOB}} = \frac{1}{n}\sum_{i=1}^{n} L\!\left(y_i,\; \frac{1}{|\mathcal{B}_i|}\sum_{b \in \mathcal{B}_i}\hat{f}^{(b)}(x_i)\right)$$
Notation
$\mathcal{B}_i$
set of all bootstrap indices $b$ for which sample $i$ was not in $D_b^*$
$|\mathcal{B}_i|$
size of that set — typically around $0.368 \times B$
$L(y_i, \cdot)$
a loss function (e.g., squared error for regression, 0-1 loss for classification)
$\hat{\varepsilon}_{\text{OOB}}$
out-of-bag error: a nearly unbiased estimate of generalisation error, requiring no separate validation set
Method · Parallel · Bagging + feature randomness

Random Forests

Breiman (2001) added a second decorrelation mechanism on top of bootstrapping: at each node split, only a random subset of features is considered as candidates. This breaks the tendency of all trees to rely on the same few strong predictors — the main source of high inter-tree correlation in plain bagging of decision trees.

Algorithm

  1. For $b = 1, \dots, B$:
    • Draw bootstrap sample $D_b^*$ from $D$.
    • Grow a decision tree $T_b$ on $D_b^*$ using the following split rule: at each node, before searching for the best split, draw a fresh random subset $\mathcal{F} \subset \{1, \dots, p\}$ of $m$ features and restrict the search to only those $m$ features.
    • Grow the tree fully (no pruning) or until a minimum leaf size is reached.
  2. Aggregate the $B$ trees as in bagging.

Choosing $m$

$$m \approx \begin{cases} \lfloor\sqrt{p}\rfloor & \text{classification} \\ \lfloor p/3 \rfloor & \text{regression} \end{cases}$$
Notation
$p$
total number of input features available
$m$
number of features randomly selected as candidates at each node split; the key hyperparameter
$\mathcal{F}$
the randomly drawn subset of $m$ feature indices at a given node; re-drawn independently at every node
$T_b$
the $b$-th fully-grown decision tree, whose splits use only features in $\mathcal{F}$ at each node

Feature importance: Mean Decrease in Impurity (MDI)

For each feature $j$, sum the weighted impurity reductions across all nodes in all trees where feature $j$ was used to split:

$$\text{Importance}(j) = \frac{1}{B}\sum_{b=1}^{B}\sum_{\substack{t \in T_b \\ \text{split on } j}} p_t \cdot \Delta I(t)$$
Notation
$t$
a node in tree $T_b$ that was split using feature $j$
$p_t$
fraction of training samples reaching node $t$ — the weight of that node's contribution
$\Delta I(t)$
reduction in node impurity (Gini or entropy for classification, MSE for regression) achieved by splitting at node $t$
Intuition: Setting $m < p$ means no single dominant feature can appear in every tree's top splits. Trees built on the remaining features must find alternative, complementary decision boundaries — this is exactly what keeps $\rho$ low while keeping individual tree accuracy adequate.
Method · Sequential · Bias reduction via reweighting

AdaBoost — Adaptive Boosting

Freund & Schapire (1997) showed that a sequence of weak classifiers (each only marginally better than random) can be combined into an arbitrarily accurate strong classifier — as long as each one focuses on the examples the previous ones got wrong. This is implemented by maintaining a distribution of weights over the training samples that gets updated after every round.

each αₜ is computed from the weighted error εₜ; misclassified samples get higher weight before the next round

Algorithm (binary classification, $y \in \{-1, +1\}$)

  1. Initialize uniform sample weights: $w_i^{(1)} = \dfrac{1}{n}$ for all $i = 1, \dots, n$.
  2. For each round $t = 1, \dots, T$:
    • Train weak learner $h_t : \mathcal{X} \to \{-1,+1\}$ on $D$ using the current weight distribution $\{w_i^{(t)}\}$.
    • Compute weighted misclassification error: $\varepsilon_t = \displaystyle\sum_{i=1}^{n} w_i^{(t)}\,\mathbb{1}(h_t(x_i) \neq y_i)$
    • Compute the model's vote weight: $\alpha_t = \dfrac{1}{2}\ln\!\left(\dfrac{1 - \varepsilon_t}{\varepsilon_t}\right)$
    • Update weights: $\tilde{w}_i^{(t+1)} = w_i^{(t)} \exp\!\left(-\alpha_t\, y_i\, h_t(x_i)\right)$
    • Normalise: $w_i^{(t+1)} = \dfrac{\tilde{w}_i^{(t+1)}}{Z_t}$, where $Z_t = \displaystyle\sum_{i=1}^{n}\tilde{w}_i^{(t+1)}$
  3. Return the strong classifier: $H(x) = \text{sign}\!\left(\displaystyle\sum_{t=1}^{T}\alpha_t\, h_t(x)\right)$
Notation
$n$
number of training samples
$T$
number of boosting rounds; each round adds one weak learner
$w_i^{(t)}$
weight of sample $i$ at round $t$ — a positive real number, all weights summing to 1
$h_t$
the weak learner trained at round $t$, typically a single-level decision tree (decision stump)
$\varepsilon_t$
weighted error rate of $h_t$; must satisfy $\varepsilon_t < 0.5$ for the algorithm to work
$\alpha_t$
vote weight for $h_t$; grows large when $\varepsilon_t \to 0$, approaches zero when $\varepsilon_t \to 0.5$
$y_i$
true label of sample $i$, encoded as $+1$ or $-1$
$h_t(x_i)$
prediction of $h_t$ on sample $i$, also in $\{-1, +1\}$
$y_i h_t(x_i)$
product is $+1$ on a correct prediction, $-1$ on a wrong one
$\tilde{w}_i^{(t+1)}$
unnormalized updated weight: decreases on correctly classified samples ($\times e^{-\alpha_t}$), increases on misclassified ones ($\times e^{+\alpha_t}$)
$Z_t$
partition function (normalizing constant) that ensures weights sum to 1 after the update
$H(x)$
final strong classifier: the sign of the weighted vote of all $T$ weak learners
$\text{sign}(\cdot)$
returns $+1$ if the argument is positive, $-1$ if negative

Exponential loss connection

AdaBoost implicitly minimises the exponential loss function by gradient descent on the function space. The training error satisfies:

$$\frac{1}{n}\sum_{i=1}^{n}\exp(-y_i\, F_T(x_i)) \;\leq\; \prod_{t=1}^{T} 2\sqrt{\varepsilon_t(1-\varepsilon_t)} \;=\; \prod_{t=1}^{T}\sqrt{1-4\gamma_t^2}$$
Notation
$F_T(x_i)$
the final score $\sum_{t=1}^{T}\alpha_t h_t(x_i)$ before the sign is applied
$\gamma_t$
edge of learner $t$: $\gamma_t = \tfrac{1}{2} - \varepsilon_t$; the amount by which each weak learner beats random ($\varepsilon_t < 0.5$ means $\gamma_t > 0$)

The training error decays exponentially in the number of rounds $T$ as long as every $\gamma_t > \gamma > 0$ — the origin of the name "boosting."

Method · Sequential · Gradient descent in function space

Gradient Boosting

Friedman (2001) reframed boosting not as a reweighting procedure but as gradient descent in the space of functions. Each new model is fit to the negative gradient of any differentiable loss function — generalising AdaBoost's exponential loss to squared error, log-loss, quantile loss, and beyond.

Algorithm (GBDT — Gradient-Boosted Decision Trees)

  1. Initialise with a constant prediction that minimises total loss: $$F_0(x) = \arg\min_{\gamma}\sum_{i=1}^{n} L(y_i,\,\gamma)$$ For MSE loss, $F_0(x) = \bar{y}$ (the training mean). For log-loss, $F_0(x) = \log(\bar{p}/(1-\bar{p}))$.
  2. For each iteration $m = 1, \dots, M$:
    • Compute pseudo-residuals (the negative gradient of the loss w.r.t. the current prediction): $$r_{im} = -\left[\frac{\partial L(y_i,\, F(x_i))}{\partial F(x_i)}\right]_{F\,=\,F_{m-1}}, \quad i = 1, \dots, n$$
    • Fit a regression tree $h_m$ to the pseudo-residuals $\{(x_i, r_{im})\}_{i=1}^{n}$; let $\{R_{jm}\}_{j=1}^{J_m}$ be its terminal node (leaf) regions.
    • Find the optimal leaf values by solving the loss minimisation within each leaf: $$\gamma_{jm} = \arg\min_{\gamma}\sum_{x_i \in R_{jm}} L\!\left(y_i,\; F_{m-1}(x_i) + \gamma\right)$$
    • Update the ensemble: $$F_m(x) = F_{m-1}(x) + \nu\,\sum_{j=1}^{J_m}\gamma_{jm}\,\mathbb{1}(x \in R_{jm})$$
  3. Return $F_M(x)$ as the final prediction.
Notation
$L(y_i, F(x_i))$
differentiable loss function — common choices: squared error $\tfrac{1}{2}(y_i - F(x_i))^2$, log-loss, Huber, quantile
$F(x)$
the additive model's prediction for input $x$ at the current stage
$M$
total number of boosting iterations (trees added)
$r_{im}$
pseudo-residual for sample $i$ at iteration $m$: the direction (in prediction space) that most reduces the loss
$h_m$
a shallow regression tree (usually depth 3–8) fit to approximate the pseudo-residuals
$J_m$
number of terminal leaf nodes in tree $h_m$
$R_{jm}$
the $j$-th leaf region of tree $m$: the set of input vectors $x$ that tree $m$ routes to its $j$-th leaf
$\gamma_{jm}$
the optimal constant prediction assigned to leaf $j$ of tree $m$, found by a one-dimensional line search
$\nu$
learning rate (shrinkage), $0 < \nu \leq 1$; scales down each tree's contribution to prevent overfitting — smaller $\nu$ requires larger $M$
$F_m(x)$
ensemble prediction after incorporating $m$ trees

Common loss functions and their pseudo-residuals

TaskLoss $L(y,F)$Pseudo-residual $r_{im}$
Regression$\tfrac{1}{2}(y_i - F)^2$$y_i - F_{m-1}(x_i)$ — the ordinary residual
Classification$\log(1 + e^{-y_i F})$$y_i - \sigma(F_{m-1}(x_i))$ where $\sigma$ is the sigmoid
Quantile ($\tau$)$\tau(y-F)^+ + (1-\tau)(F-y)^+$$\tau\,\mathbb{1}(y_i > F) - (1-\tau)\,\mathbb{1}(y_i \leq F)$
Key insight: For squared error, the pseudo-residual is literally $y_i - F_{m-1}(x_i)$ — the ordinary residual — so each tree is truly "fitting the leftover error." For other losses, the pseudo-residual is a generalised notion of error that points in the steepest descent direction.
Method · Sequential · Regularised second-order boosting

XGBoost — Extreme Gradient Boosting

Chen & Guestrin (2016) extended gradient boosting by (a) using a second-order Taylor expansion of the loss to find better leaf values analytically, and (b) adding explicit regularisation terms on tree complexity directly into the objective — not as a post-hoc penalty but baked into every split decision.

Regularised objective at iteration $m$

At each boosting round we want to add a tree $f_m$ that minimises:

$$\mathcal{L}^{(m)} = \sum_{i=1}^{n} L\!\left(y_i,\; \hat{y}_i^{(m-1)} + f_m(x_i)\right) + \Omega(f_m)$$
$$\text{where} \quad \Omega(f_m) = \gamma\, T + \frac{1}{2}\lambda\sum_{j=1}^{T}w_j^2$$
Notation
$\mathcal{L}^{(m)}$
total objective to minimise at boosting round $m$
$\hat{y}_i^{(m-1)}$
current ensemble's prediction for sample $i$ after $m{-}1$ trees
$f_m(x_i)$
the new tree being added at iteration $m$, mapping inputs to real-valued leaf scores
$\Omega(f_m)$
regularisation penalty on the complexity of tree $f_m$
$T$
number of leaves in tree $f_m$
$w_j$
the score (output value) of the $j$-th leaf in tree $f_m$
$\gamma$
minimum loss reduction required to make a split — penalises trees with many leaves
$\lambda$
L2 regularisation coefficient on leaf scores — shrinks individual leaf values toward zero

Second-order Taylor approximation

Expanding $L$ around the current prediction to second order:

$$\mathcal{L}^{(m)} \approx \sum_{i=1}^{n}\!\left[g_i\, f_m(x_i) + \frac{1}{2}h_i\, f_m(x_i)^2\right] + \Omega(f_m) + \text{const}$$
Notation
$g_i$
first-order derivative (gradient): $g_i = \partial L(y_i, \hat{y}_i^{(m-1)}) / \partial \hat{y}_i^{(m-1)}$
$h_i$
second-order derivative (Hessian): $h_i = \partial^2 L(y_i, \hat{y}_i^{(m-1)}) / \partial (\hat{y}_i^{(m-1)})^2$

Optimal leaf weights and split gain

Given a fixed tree structure, the optimal weight for leaf $j$ is found analytically:

$$w_j^* = -\frac{G_j}{H_j + \lambda} \qquad\text{where}\quad G_j = \sum_{i \in I_j} g_i,\quad H_j = \sum_{i \in I_j} h_i$$

The gain of splitting a leaf $I$ into left child $I_L$ and right child $I_R$ is:

$$\text{Gain} = \frac{1}{2}\!\left[\frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda}\right] - \gamma$$
Notation
$I_j$
set of sample indices that fall into leaf $j$
$G_j$
sum of first-order gradients in leaf $j$
$H_j$
sum of second-order Hessians in leaf $j$
$w_j^*$
optimal leaf weight: the value that minimises the (regularised) approximate loss over leaf $j$
$I_L, I_R$
sample sets routed to the left and right child after a candidate split
$G_L, G_R$
sum of gradients in the left and right child respectively
$H_L, H_R$
sum of Hessians in the left and right child respectively
$\text{Gain}$
net loss reduction achieved by this split; a split is made only when Gain $> 0$ (i.e., the reduction outweighs the $\gamma$ penalty)
Why two derivatives? The first-order gradient $g_i$ says "which direction to move." The second-order Hessian $h_i$ says "how confident we should be in that direction." Using both gives a better-calibrated step than plain gradient boosting, which uses only $g_i$ (equivalent to assuming the loss is quadratic everywhere with $h_i = 1$).

XGBoost additional features

Beyond the core second-order objective, XGBoost introduces several engineering and algorithmic advances: column subsampling (like Random Forests, a random fraction of features is sampled per tree or per split), row subsampling (stochastic gradient boosting), and a weighted quantile sketch for approximate split finding on large datasets.

Method · Sequential · Histogram-based, leaf-wise growth

LightGBM

Ke et al. (2017) kept the same second-order regularised objective as XGBoost but redesigned the algorithm to be faster and more memory-efficient on large datasets through two key innovations: Gradient-based One-Side Sampling (GOSS) and Exclusive Feature Bundling (EFB), combined with histogram-based split finding and a leaf-wise (best-first) tree growth strategy.

Histogram-based split finding

Instead of iterating over every unique feature value to find the best split (as in classical GBDT), LightGBM bins each continuous feature into $K$ discrete buckets and accumulates gradient statistics per bin:

$$G_k = \sum_{i:\, x_{ij} \in \text{bin}_k} g_i \qquad H_k = \sum_{i:\, x_{ij} \in \text{bin}_k} h_i \qquad k = 1, \dots, K$$

Splits are then evaluated over $K$ bin boundaries rather than $n$ unique values, reducing split-finding complexity from $O(n)$ to $O(K)$ per feature.

Notation
$K$
number of bins per feature — a hyperparameter (typical default: 255); smaller $K$ = faster but coarser splits
$\text{bin}_k$
the $k$-th interval of binned feature values
$G_k, H_k$
accumulated gradient and Hessian statistics for all samples whose feature value falls in $\text{bin}_k$

GOSS — Gradient-based One-Side Sampling

Training instances with large gradients carry more information about the loss landscape. GOSS keeps all high-gradient samples but randomly drops a fraction of low-gradient ones, compensating with a scaling factor to avoid introducing bias:

  1. Sort samples by $|g_i|$; keep the top $a \cdot n$ samples with the largest absolute gradients (set $A$).
  2. From the remaining $n - a \cdot n$ samples (set $A^c$), randomly draw a subset $B$ of size $b \cdot |A^c|$.
  3. When computing gradient statistics for a split on subset $A \cup B$, multiply the gradients of samples in $B$ by the amplification factor $\dfrac{1-a}{b}$ to restore unbiasedness.
Notation
$a$
top sampling ratio: fraction of instances with the largest gradients retained in full (e.g., $a=0.2$)
$b$
random sampling ratio: fraction of remaining (low-gradient) instances sampled (e.g., $b=0.1$)
$A$
set of the $a \cdot n$ samples with the largest $|g_i|$ — always included in split computations
$B$
random subset of $b \cdot (1-a) \cdot n$ low-gradient samples — included with upscaled gradients
$\dfrac{1-a}{b}$
amplification factor applied to gradients of samples in $B$; corrects the bias introduced by under-representing low-gradient instances

EFB — Exclusive Feature Bundling

Many features in high-dimensional sparse datasets are mutually exclusive — they never both take non-zero values simultaneously for the same sample. EFB bundles such features into a single feature, reducing the effective number of features and saving memory and computation. Finding the optimal bundling is NP-hard, so LightGBM uses a greedy approximation via graph colouring.

Leaf-wise vs. level-wise growth

Most GBDT implementations grow trees level-by-level (all nodes at depth $d$ before splitting any node at depth $d+1$). LightGBM grows leaf-wise: at each step it splits whichever existing leaf has the maximum gain, regardless of depth. Given a fixed number of leaves, this typically produces better loss reduction but can lead to deeper, less balanced trees — controlled by the max_depth and num_leaves hyperparameters.

LightGBM vs XGBoost: Both optimise the same regularised second-order objective. LightGBM is generally faster on large datasets (histogram binning + GOSS + EFB) and often converges in fewer trees due to leaf-wise growth. XGBoost can sometimes generalise better on smaller datasets because level-wise growth is a stronger form of regularisation.
Method · Parallel base + learned combiner

Stacking — Stacked Generalization

Wolpert (1992) observed that averaging or majority-voting treats all base models equally, ignoring the fact that different models may be better in different input regions. Stacking trains a meta-learner to optimally blend base models' predictions, learning from the data which models to trust and when.

dashed lines = out-of-fold meta-features (no leakage); solid lines = full-data training at inference time

Algorithm (K-fold stacking)

  1. Partition the training set $D$ into $K$ non-overlapping folds $D_1, \dots, D_K$.
  2. For each base learner $l = 1, \dots, L$ and each fold $k = 1, \dots, K$:
    • Train $h_l$ on $D \setminus D_k$ (all folds except fold $k$).
    • Predict on hold-out fold $D_k$: record $z_i^{(l)} = h_l^{(-k)}(x_i)$ for each $i \in D_k$.
  3. After all $K$ folds, every sample $i$ has an out-of-fold prediction $z_i^{(l)}$ from every base learner $l$.
  4. Construct meta-dataset: rows are samples $i$, columns are $z_i^{(1)}, \dots, z_i^{(L)}$ (and optionally the original features $x_i$).
  5. Train the meta-learner $g$ on the meta-dataset against the true labels $y_i$.
  6. For deployment: retrain each $h_l$ on the full $D$, then predict on a new test point $x^*$ as: $$\hat{y}^* = g\!\left(h_1(x^*), h_2(x^*), \dots, h_L(x^*)\right)$$
Notation
$K$
number of cross-validation folds; typical values: 5 or 10
$L$
number of level-0 (base) learners
$h_l^{(-k)}$
learner $l$ trained on all folds except the $k$-th; the superscript $(-k)$ means "trained without fold $k$"
$z_i^{(l)}$
out-of-fold prediction for sample $i$ from base learner $l$ — this is the $l$-th meta-feature for sample $i$
$\mathbf{z}_i$
vector $(z_i^{(1)}, \dots, z_i^{(L)})$: the full set of meta-features for sample $i$
$g$
meta-learner trained on meta-features; often logistic regression, ridge regression, or a shallow tree
$\hat{y}^*$
the final stacking prediction for a new test point $x^*$

Why out-of-fold matters

If base learner $h_l$ is trained on the full data including sample $i$, its prediction on $i$ contains "leaked" memorisation of $i$'s label. The meta-learner would learn to trust overfit predictions, producing a system that looks excellent on training data but fails to generalise. Out-of-fold predictions guarantee that $z_i^{(l)}$ is always computed by a model that has never seen sample $i$ during training.

Multi-layer stacking: Nothing prevents the meta-learner $g$ from being itself a stacking ensemble. In practice, more than two layers rarely improves performance and significantly increases the risk of overfitting; two-layer stacking is the standard.
Method · Parallel · Fixed combination rule

Voting Classifiers

Voting is the most transparent ensemble strategy: train heterogeneous models independently on the same data and combine their predictions with a predetermined rule — no second model, no learned weights. It is a strong baseline whenever quick results are needed.

hard voting: two votes for Class A, one for Class B → final answer is Class A

Hard voting

Each classifier contributes exactly one vote for its predicted class label. The plurality winner is chosen:

$$\hat{y}_{\text{hard}} = \arg\max_{k \in \mathcal{Y}}\;\sum_{l=1}^{L}\mathbb{1}(h_l(x) = k)$$

Soft voting (weighted average of probabilities)

Each classifier outputs a probability vector over all classes. Those probability vectors are averaged (possibly with per-model importance weights) and the class with the highest average probability wins:

$$\hat{y}_{\text{soft}} = \arg\max_{k \in \mathcal{Y}}\;\sum_{l=1}^{L} w_l\, p_l(k \mid x) \qquad \text{subject to}\quad \sum_{l=1}^{L} w_l = 1,\quad w_l \geq 0$$
Notation
$L$
number of classifiers being combined
$\mathcal{Y}$
set of all possible class labels
$k$
a candidate class label
$h_l(x)$
the hard class label predicted by classifier $l$ for input $x$
$p_l(k \mid x)$
estimated probability that classifier $l$ assigns to class $k$ — requires the classifier to output calibrated probabilities
$w_l$
importance weight for classifier $l$; with equal weighting $w_l = 1/L$ for every $l$

Weighted majority vote (for regression)

For regression, the voting analogue is a weighted average:

$$\hat{y} = \sum_{l=1}^{L} w_l\, h_l(x) \qquad \text{with}\quad \sum_{l=1}^{L} w_l = 1$$

Soft voting consistently outperforms hard voting when the probability estimates are well calibrated, because it retains confidence information — a near-certain prediction from one model is treated more seriously than a barely-marginal prediction from another.

Unified view: bias-variance perspective

$$\underbrace{\text{Bagging, RF, Voting}}_{\rho \downarrow,\; \sigma^2 \text{ unchanged}} \qquad \underbrace{\text{AdaBoost, GB, XGBoost, LightGBM}}_{\text{Bias}^2 \downarrow,\; \text{Var may } \uparrow \text{ without reg.}} \qquad \underbrace{\text{Stacking}}_{\text{both } \downarrow}$$

In every method, the underlying goal is the same: reduce total expected error. Parallel methods primarily attack the variance term by making models diverse ($\rho$ small). Sequential boosting methods primarily attack the bias term by building towards the correct answer step by step. Stacking does both by learning which base model is best in each region of the input space.
